# Componentes de terceiros

As dependências são obtidas pelos respectivos gerenciadores. As licenças e os avisos de cada componente acompanham suas distribuições originais. As versões das dependências Rust, incluindo as transitivas, estão em `Cargo.lock`.

| Componente | Licença declarada | Distribuição |
| --- | --- | --- |
| rawzip | MIT | [rawzip](https://crates.io/crates/rawzip/0.5.2) |
| clap | MIT ou Apache-2.0 | [clap](https://crates.io/crates/clap) |
| libc | MIT ou Apache-2.0 | [libc](https://crates.io/crates/libc) |
| serde | MIT ou Apache-2.0 | [serde](https://crates.io/crates/serde) |
| serde_json | MIT ou Apache-2.0 | [serde_json](https://crates.io/crates/serde_json) |
| flate2 | MIT ou Apache-2.0 | [flate2](https://crates.io/crates/flate2) |
| tempfile | MIT ou Apache-2.0 | [tempfile](https://crates.io/crates/tempfile) |
| GitHub Actions Checkout | MIT | [actions/checkout](https://github.com/actions/checkout/blob/v6.0.2/LICENSE) |
